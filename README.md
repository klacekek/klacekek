## Heater Tracker

An Android bankroll tracker tailored for poker tournaments. Record buy-ins, payouts, dates, game types, and notes while monitoring your heater (or cooler) through instant summaries and a cumulative profit graph.

### Features

- 📓 Log tournament sessions with date, buy-in, payout, format, and optional notes
- 📈 Visualize cumulative profit/loss across time with an inline chart
- 💰 Review total profit, total buy-ins, and in-the-money (ITM) percentage at a glance
- 🧮 Automatic ITM detection when payouts are greater than zero
- 📝 Seeded with sample data so you can explore the UI immediately after installing

### Getting Started

1. Open the project in Android Studio (Giraffe or newer recommended).
2. Let Gradle sync and download dependencies.
3. Deploy the `app` module to an emulator or Android device running API level 24 or later.

> **Tip:** Use the floating action button to add new tournaments. Enter buy-in and payout values with digits only, and dates in the `YYYY-MM-DD` format.
